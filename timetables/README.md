# JR / 巴士時刻表與乘車附件圖片存放目錄 (timetables)

將您的時刻表截圖、乘車指南或票券圖檔放入此資料夾中，例如：
- `d1_okayama_bus.jpg` (Day 1 機場巴士時刻表)
- `d2_jr_tsuyama.jpg` (Day 2 JR 津山線時刻表)
- `d3_tottori_sakyu_bus.jpg` (Day 3 鳥取砂丘巴士時刻表)

放進此資料夾後：
1. 在網頁各搭乘區間點擊 **【🖼️ 連結圖檔】** 輸入檔名（例如 `timetables/d1_okayama_bus.jpg` 或直接輸入 `d1_okayama_bus.jpg`）。
2. 將此資料夾與程式碼一同 `git add .`、`git commit -m "add timetable images"`、`git push` 到 GitHub。
3. 這樣任何電腦或手機連到 GitHub Pages 時，都能直接看到實體圖檔！
